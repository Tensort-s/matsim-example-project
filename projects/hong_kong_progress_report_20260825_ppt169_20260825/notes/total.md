# 01_cover

这次汇报集中说明香港多模式 MATSim 在最近一阶段完成了什么变化。核心不是单独增加几个参数，而是把港币成本、稀缺实体车辆和信号控制放进同一个可以回到事件记录检查的运行框架。后面用八组阶段性成果逐项说明这些能力，其中既有全港尺度结果，也有具体到个人、车辆、链接和秒级时间的机械验证。本次汇报只讨论已经完成并形成证据的部分，不设置未来展望。

---

# 02_baseline

先用这一页界定比较基线。原始版本已经能够生成活动计划和多模式候选，提供道路与公共交通供给，并通过 MATSim 的效用评分和迭代选择形成出行结果；因此它已经具备需求、供给和选择的基本骨架。基线尚未引入四项能力：私家车的能耗、过路费和停车费不能以港币审计，公共交通票价没有进入方式选择成本，校巴缺少接驳步行与登乘的事件级验证，家庭私家车也还不是有归属和共享时序的物理资源。后面的十页不再重复旧版本，而是集中展示这些缺口如何被补上。

---

# 03_model_evolution

这张图把本轮工作放回整个模型体系中理解。中央地图聚合了 iteration 49 中七十四万二千一百八十九个已实现行程，并映射到十八区，所以后续成本、车辆和控制结果共享同一个运行背景，而不是互不相干的示例。原有计划与供给骨架之上，现在形成了四个可连接层：car、PT 和 Taxi 的港币成本，家庭车辆、校巴和有限出租车队构成的物理资源，信号系统与绿波偏移构成的控制层，以及命名主体、事件时间和显式缺失值构成的审计层。需要强调，这里使用的是候选或验证结果，用于证明机制已经可以运行，并不重新定义已经采用的生产情景。

# 04_school_bus_repair

校巴案例说明一个看似很小的时间处理问题会改变实体车辆交互。对学生 hk_person_00632810，run56 中逐链接整数取整使其在七点三十八分十七秒到达，而车辆的登乘事件发生在七点三十八分十四秒，因此晚了三秒并错过车辆。改用连续链接时长后，run57 的到达时间提前到七点三十八分零七秒，恢复了成功登乘。图的下半部分显示这十秒误差如何在二十条步行链接上逐步累积，所以修复针对的是可复现的机械原因，而不是人为修改个人计划。

# 05_household_car

这一页把 private car 从可以随时选择的方式标签，转化为家庭共享的物理资源。案例家庭是 hk_hh_1251667，驾驶者是 hk_person_03051340，学生是 hk_person_03051341，实际使用的车辆是 hk_vehicle_0210204。事件时间线显示同一辆车先完成送学，再继续到工作地点，下午接回学生，最后共同返程；车辆在哪里、由谁占用和何时可用开始共同约束家庭联合计划。图中保留的 Walk 方案用于比较计划选择，但其中的 MATSim score 是效用值，不是港币金额，也不能解释为对真实家庭偏好的观测。

# 06_taxi_fleet

出租车模块的主要变化，是把抽象方式选择落到有限车队的运营账本上。当前结果中有一万五千五百辆实体出租车，完成十八万六千一百四十四个请求，仿真终点仍有十七个请求在等待，同时车队空驶 VKT 占百分之十六点五。左侧流量地图与径向的请求—在役车辆图来自同一执行结果，因此可以同时看到空间服务、小时活动和资源利用。需要区分运营与金额边界：其他页面使用的 Taxi 金额目前按实际载客距离计算，等待效用还没有折算成港币。

# 07_car_cost

这里展示的是一次真正执行的私家车行程，而不是设定一个统一惩罚分。案例 hk_person_01925581 的总成本是港币一百二十二点七元，其中二十点七元来自路线能耗，三十元来自车辆在实际 LinkEnter 时间进入过海隧道，七十二元来自已结算的目的地停车。三个组成部分都可以沿事件和规则回溯，因此能够解释为什么某次行程得到这个金额。固定拥有成本仍保留在 vehicle-day sidecar 中，没有为了凑齐总价而任意分摊到这次行程。

---

# 08_pt_fare

公共交通票价不采用直线距离或线路长度近似，而是根据乘客实际经历的上车、下车和换乘链进行严格键值解析。从 Central–Admiralty 一点二公里来源区出发的共一万零六十六条实际行程中，九千七百九十二条获得完整严格票价，解析率为百分之九十七点二八，并覆盖四十二个主要目的地站点。图中四条真实行程进一步展开了 MTR、巴士、渡轮和换乘链的逐段金额，所用十张票价表和 crosswalk 通过 SHA256 校验。当前逻辑明确不使用距离、反向顺序、整条线路或零值回退，未解析链保持缺失；金额采用成人参考和基础八达通规则，个人优惠与换乘折扣尚未建模。

# 09_cost_geography

在单次行程成本可审计之后，这一页把结果扩展到全香港固定网格。定价行程总量是五十六万六千四百三十七，其中完整解析的 PT 行程三十六万四千一百六十，完整 private-car 行程一万六千一百三十三，完成的 Taxi 行程十八万六千一百四十四。四幅地图分别呈现总体、PT、私家车和 Taxi 的平均模型规则港币成本，从而展示真实金额口径下的空间差异。这里特别保留 null 与零的区别：无法解析的链仍是 null，不会被静默写成零成本；私家车和 Taxi 的纳入项、排除项也都保留在图下注释中。

# 10_signals_greenwave

道路供给现在不再只表现为静态容量，Candidate11 已经把信号控制编译进全港网络。当前包包含一千四百四十五个 signal systems、三千二百四十三个 groups 和六千九百四十一个 controlled turns；十四条已实现走廊涉及四十七个不同的走廊信号系统。图中 corridor_002 的反向方向使用零、三、八和十二秒的固定偏移，并在二十点十五分到二十点三十分的高峰时段用时空图验证协调关系。全港分布、局部受控转向和绿波时空图共享同一套系统定义，但周期方案和偏移仍是研究候选，不能表述为对香港真实信号配时的观测。

---

# 11_summary

把八组证据放在一起，本轮升级可以归纳为三个方向。第一是货币化：私家车成本构成、严格 PT 票价和全港港币成本表面让出行代价进入真实金额口径；第二是实体化：家庭共享车辆、校巴登乘和有限出租车队让方式选择受到资源归属和时序约束；第三是可审计化：person、vehicle、event、信号系统、corridor offset、null 与排除项都能回到明确记录。最终的变化可以概括为，从模型“可以运行”推进到“可以解释每一次关键运行结果”。这些仍是候选与验证成果，不会被静默等同于生产情景或真实香港行为观测。
