# Household joint-plan potential audit v1 (historical, superseded)

This directory preserves the first read-only screen for provenance. It is not
the adopted candidate registry. The v1 detour screen both required the driver
and passenger origins to be within 500 m and omitted the driver-to-passenger
pickup segment from its detour geometry. It therefore under-counted feasible
household pickup alternatives (5,030 pairs in 3,844 households).

Use `../household_joint_plan_potential_audit_v2/` for implementation and
validation. No simulation plan was created or selected from v1.
